# The Last Coin — demo web

Demo jugable en el navegador: **https://alejandrogomezdelara.github.io/the-last-coin-web/**

- *Jugar con amigos*: uno crea una sala (2 a 16, par) y pasa el código; los demás entran con él.
- *Contra la IA*: battle royale de 16 o 1 vs 1, sin red.

Solo contiene la build WebGL; el código del juego está en otro repositorio.
